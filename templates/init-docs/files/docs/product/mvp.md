# MVP

> Status: **Draft**

This document defines the **minimum viable product (MVP)**: the smallest release
of the product that delivers the core promise of the [vision](vision.md) to one
kind of user, end to end. It decides what is built first. It does not change the
vision: everything left out here is deferred, not dropped.

The [requirements](../requirements/) stay the source of truth for behaviour.
This document lists which requirements the MVP needs, which already exist and
which still have to be written.
